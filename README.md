# Estoque Fácil
PHP e MySQL. Importe banco.sql no phpMyAdmin, copie config.example.php para config.php e configure as credenciais e a senha administrativa. Envie index.php, config.php e style.css para htdocs no InfinityFree. O histórico é gravado pelo PHP na mesma transação do CRUD, sem triggers. Não publique config.php.
